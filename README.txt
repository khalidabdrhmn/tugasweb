WEBSITE PROFIL KHALID ABDUL ROHMAN
====================================

File:
- index.html
- style.css
- script.js

CARA MENAMBAHKAN FOTO:
1. Siapkan foto pribadi dengan format JPG atau PNG.
2. Ubah nama foto menjadi:
   foto-profil.jpg
3. Masukkan foto tersebut ke folder yang sama dengan index.html.
4. Buka index.html menggunakan Google Chrome.

Contoh struktur folder:

website-profil-khalid/
│
├── index.html
├── style.css
├── script.js
└── foto-profil.jpg

Jika nama foto kamu berbeda, misalnya:
khalid.png

Maka buka index.html menggunakan editor teks dan ubah:
src="foto-profil.jpg"

menjadi:
src="khalid.png"

WEBSITE:
Website dapat langsung dijalankan dengan membuka index.html.
Tidak membutuhkan XAMPP, database, atau server.

Catatan:
Website menggunakan Google Fonts melalui internet. Jika internet
tidak tersedia, website tetap berjalan tetapi menggunakan font cadangan.
